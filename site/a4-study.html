Scope & Physical Validation Boundary: This n = 60 pilot evaluated headless MuJoCo stereo head-camera renders alongside deterministic simulator state. Because simulated telemetry defined the pilot ground truth, independent physical instrument accuracy (variance, settle time, false-pass/fail bounds) awaits execution of the pre-registered n = 240 physical A4 study starting on the Stage-1 bench ($1,291 core sensor subtotal: Radwag WTC 2000 $466 + Basler ace 2 & 8 mm lens $825; head stereo camera and H1/H4 fixtures budgeted separately, with human technicians executing pre-arm manipulations).

I · Methods, Pipeline Identity & Scoring Formulas

Episodes are balanced across four design strata (15 each: S1 clean control, S2 obvious fail where all 4 pipelines hit 0/15 false passes, S3 borderline fail, and S4 adversarial optical decoy), with stop-use thresholds frozen before data collection in spec/JUDGE-EXPERIMENT-v0.md. We report two complementary accuracy metrics from the identical 60-trial confusion matrices: Binary Classification Accuracy (the κ / FPR / FFR rule treating FAIL, PARTIAL, and UNSURE uniformly as non-pass, giving 46/60–52/60) and Exact Unabstained Accuracy (requiring an explicit matching judgment, penalizing UNSURE on both classes: coverage − FP − FN, giving 34/60–50/60). Because aggregate FPR depends on the designed S3/S4 mix, stratum rates are listed separately below. Key robodojo_astra is retained in the JSON dataset for gpt-6-astra.
